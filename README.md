# Python ゲームで学ぶ 12 週間

Python 学習計画書の「成果物」に合わせたサンプルゲーム集です。
各週の課題を自分で作ったあとに、答え合わせとして読んでください。

| 週 | ファイル | 内容 | 使う知識 |
| --- | --- | --- | --- |
| 4 | `week04_kazuate.py` | 数当てゲーム。難易度3段階、回数を使い切ると負け | 変数、if、while、random、辞書 |
| 5 | `week05_janken.py` | じゃんけん10回勝負。コンピューターがあなたのクセを読む | 関数、リスト、辞書 |
| 6 | `week06_kazuate_highscore.py` | ランキング（上位5位）付き数当て | ファイル保存、並べ替え |
| 7 | `week07_text_battle.py` | 文字バトル。魔法・レベルアップ・敵ごとの特技あり | クラス、継承 |
| 8〜10 | `week10_yoke_game.py` | 隕石をよけて星を拾う宇宙船ゲーム。効果音・画面揺れ付き | Pygame、当たり判定、効果音 |
| 11〜12 | 自分で作る | オリジナルゲーム | ここまでの全部 |

## 動かし方

```bash
# 第4〜7週（Python だけで動く）
python week04_kazuate.py

# 第8〜10週（Pygame が必要）
pip install pygame
python week10_yoke_game.py
```

よけゲームの操作: スペースでスタート、← → キー（または A / D）で移動、Esc で終了。
生き残った 1 秒ごとに 1 点、星を 1 つ拾うごとに 5 点。10 秒ごとにレベルが上がり、隕石が増えて速くなります。

文字バトルのヒント: 攻撃だけではドラゴンに勝てません。ドラゴンが息を吸いこんだら、次のターンの大ダメージに備えましょう。

## おすすめの改造（練習問題）

- 数当て: 「あと少し！」（差が 5 以内）のヒントを出す
- じゃんけん: 「直前に出した手のあとに何を出すか」まで読むようにする
- ランキング: 難易度ごとに別のランキングにする
- 文字バトル: 宝箱（回復薬が増える）や、逃げるコマンドを追加する
- よけゲーム:
  - 画像を使う: `pygame.image.load("player.png")` で、図形の代わりに自分で描いた絵を表示する
  - 日本語を表示する: `pygame.font.SysFont("meiryo", 36)`（Windows）や
    `pygame.font.SysFont("hiraginosans", 36)`（Mac）を使う
  - 一定時間だけ無敵になるアイテムを追加する

## 第11〜12週：オリジナルゲーム

3. 「動く最小のもの」を先に作り、少しずつ足していく
4. できたら GitHub にコミットして公開する
